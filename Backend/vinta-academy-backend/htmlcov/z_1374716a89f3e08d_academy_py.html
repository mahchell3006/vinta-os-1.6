89 # ------------------------------------------------------------------ 

90 # Billing Rules — per-academy edge-case toggles. 

91 # 

92 # These are read-only configuration values consulted at decision points 

93 # in the billing flow, never at startup. Changing one mid-day takes 

94 # effect on the very next attendance check-in: no restart, no cache 

95 # invalidation, no migration. Each toggle is independent and has a 

96 # sensible default, so an academy that never opens Settings still runs. 

97 # 

98 # `server_default` is set alongside the Python `default` so the additive 

99 # ALTER TABLE that introduces these columns can backfill existing rows. 

100 # ------------------------------------------------------------------ 

101 

102 # Toggle 1 — charge for missed sessions. True: an ABSENT student still 

103 # spends a credit. False: only PRESENT spends one; absences are free retries. 

104 absence_consumes_credit: Mapped[bool] = mapped_column( 

105 Boolean, default=True, server_default="1", nullable=False 

106 ) 

107 

108 # Toggle 2 — count sessions missed during a payment gap. True: sessions 

109 # missed while overdue are retroactively charged against the NEXT 

110 # subscription. False: a new payment always starts a clean cycle. 

111 count_gap_sessions: Mapped[bool] = mapped_column( 

112 Boolean, default=False, server_default="0", nullable=False 

113 ) 

114 

115 # Toggle 5 — restore credits when a class is cancelled AFTER students were 

116 # already checked in and charged. False = the academy keeps the money. 

117 restore_credits_on_cancellation: Mapped[bool] = mapped_column( 

118 Boolean, default=False, server_default="0", nullable=False 

119 ) 

120 

121 # Toggle 6 — auto-mark everyone PRESENT for a FREE session. True: no

124 Boolean, default=True, server_default="1", nullable=False
